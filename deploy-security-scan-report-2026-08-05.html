2. 발견된 문제와 조치

🔴 P0 1건 — 사회혁신가 응답 시트 공유 설정이 열려 있음. 7/10 스캔 때는 HTTP 401(잠김)이었으나 8/5 현재 200(공개)으로 바뀜 — 그 사이 어느 시점에 공유 설정이 "링크가 있는 모든 사용자"로 변경된 것으로 추정. 시트 ID는 공개 레포 README와 git 히스토리에 있으므로, 시트가 열려 있는 동안은 사실상 개인정보 공개 상태.

  1. 조치 완료 (2026-08-05): 소유자(조안)가 공유 설정을 카카오임팩트 조직 계정 사용자 뷰어 전용으로 변경 (권한 변경은 클로드가 아닌 소유자가 직접 수행)
  2. 재검증 완료: gviz 비로그인 테스트 HTTP 401 확인 → 배포 재개
  3. 추가 조치: README의 시트 직링크 제거 — 대시보드는 시트가 아닌 Apps Script 웹앱으로만 연동
  4. 남은 확인: 언제·왜 열렸는지 경위 미파악 (다른 도구가 gviz 자동 로드용으로 열었을 가능성 — 해당 도구가 있다면 Apps Script 방식으로 전환 권장)

멘토 대시보드 추가분 자체는 문제 없음: 소스에 신청 데이터 0건, 연락처는 Apps Script에서 아예 읽지 않는 구조(전화·이메일 컬럼 미참조), 멘토 시트는 잠겨 있음.

4. 잔여 리스크

  • 사회혁신가 시트가 열려 있던 기간 불명 (7/10 잠김 확인 ~ 8/5 공개 발견·조치 사이). 노출 데이터: 신청자 99명의 연락처·이메일 포함 응답 전체. 실제 유출 정황은 확인 불가 — 기간·경위 파악 후 필요 시 개인정보 노출 대응(신청자 고지 등) 검토 권장
  • 현재 조직 계정 뷰어 전용: 외부 노출은 차단됐으나 연락처 포함 원본을 재단 계정 전체가 열람 가능한 상태 — 운영에 필요 없다면 담당자 지정 공유로 좁히는 것 권장
